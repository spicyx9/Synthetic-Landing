## Correction 404 (contenu exact du fichier `404.html` à créer à la racine du repo)

Vercel sert automatiquement `404.html` pour toute URL inconnue d'un déploiement statique, avec le code 404 conservé. Le fichier réutilise les feuilles de style existantes et propose les deux langues, puisque la langue du visiteur n'est pas connue à ce stade.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="robots" content="noindex">
  <title>Page not found | Synthetic Swarm</title>
  <link rel="icon" href="/assets/favicon.png" type="image/png">
  <link rel="stylesheet" href="/styles.css">
  <link rel="stylesheet" href="/site-pages.css?v=header-actions-2">
</head>
<body>
  <header class="header">
    <div class="header-inner">
      <a href="/" class="logo"><img src="/assets/logo-black-narrow.png" alt="" class="logo-icon" width="20" height="20">Synthetic Swarm</a>
    </div>
  </header>
  <main id="main" class="content-page" tabindex="-1">
    <section class="page-intro">
      <span class="page-kicker">404</span>
      <h1>This page does not exist.</h1>
      <p>The address may be wrong or the page may have moved. <a href="/">Back to the home page</a>, <a href="/pricing">see pricing</a> or <a href="/contact">contact us</a>.</p>
      <p lang="fr">Cette page n'existe pas. L'adresse est peut-être erronée ou la page a été déplacée. <a href="/index-fr">Retour à l'accueil</a>, <a href="/tarifs">voir les tarifs</a> ou <a href="/contact-fr">nous contacter</a>.</p>
    </section>
  </main>
</body>
</html>
```

Après déploiement : `curl -sD - -o /dev/null https://www.syntheticswarm.ai/nexistepas` doit renvoyer `HTTP/2 404` avec `content-type: text/html; charset=utf-8`.
